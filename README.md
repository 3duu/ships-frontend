# 💘 Ships — React Native Dating App Frontend

This is the React Native frontend for **Ships**, a location-based dating app (similar to Happn), built using:

- 📱 React Native + Expo
- ⚛️ TypeScript
- 🔐 Secure Auth (JWT, Refresh Tokens, Secure Storage)
- 📍 Geolocation & Swipe Queue
- 🎨 Clean UI with Animated Multi-Step Registration
- 🔄 Realtime Chat via WebSockets
